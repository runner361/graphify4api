注册单个设备
======

归属于某个产品下的设备实体，每个设备具有一个唯一的标识码。设备可以是直连物联网平台的设备，也可以是代理子设备连接物联网平台的网关。您可以在物联网平台注册您的实体设备，通过平台分配的设备ID和密钥，在集成了SDK后，您的设备可以接入到物联网平台，实现与平台的通信及交互。

物联网平台支持通过应用服务器调用[创建设备](https://support.huaweicloud.com/api-iothub/iot_06_v5_0046.html)接口，或者在控制台上注册单个设备。本文介绍如何在控制台上注册单个设备。

#### 操作步骤

1. 访问[设备接入服务](https://www.huaweicloud.com/product/iothub.html)，单击“管理控制台”进入设备接入控制台。选择您的实例，单击实例卡片进入。
2. 在左侧导航栏选择“设备 >  所有设备”，单击“注册设备”，按照如下表格填写参数后，单击“确定”。

   **图1** 设备-注册密钥设备   
   ![](https://support.huaweicloud.com/usermanual-iothub/figure/zh-cn_image_0000001950367894.png "点击放大")

   ![](https://res-static.hc-cdn.cn/aem/content/dam/cloudbu-site/archive/china/zh-cn/support/resource/framework/v3/images/expand-table.svg)

   **表1** 注册密钥设备

   | 参数名称 | 说明 |
   | --- | --- |
   | 所属资源空间 | **参数说明：**选择设备所属的资源空间。 |
   | 所属产品 | **参数说明：**选择设备所属的产品。  只有在[这里](https://support.huaweicloud.com/usermanual-iothub/iot_01_0054.html)创建了产品，此处才可以选择具体的产品。如没有，请先创建产品。 |
   | 设备标识码 | **参数说明：**即node\_id，填写为设备的IMEI、MAC地址或Serial No；若没有真实设备，填写自定义字符串，由英文字母、数字、连接号-和下划线\_组成。 |
   | 设备ID | **参数说明：**设备ID，用于唯一标识一个设备。如果携带该参数，平台将设备ID设置为该参数值；如果不携带该参数，设备ID由物联网平台分配获得，生成规则为product\_id + \_ + node\_id拼接而成。 |
   | 设备名称 | **参数说明：**即device\_name，可自定义。 |
   | 设备描述 | **参数说明：**设备的描述信息，可自定义。 |
   | 设备认证类型 | **参数说明：**  * 密钥：设备通过密钥验证身份。 * X.509证书：设备使用X.509证书验证身份。 |
   | 密钥 | **参数说明：**设备密钥，可自定义，不填写物联网平台会自动生成。 |
   | 指纹 | **参数说明：**当“设备认证类型”选择“X.509证书”时填写，导入[设备侧预置的设备证书](https://support.huaweicloud.com/usermanual-iothub/iot_01_0055.html)对应的指纹，在OpenSSL执行**openssl x509 -fingerprint -sha256 -in deviceCert.pe****m**命令可查询。    填写时需要删除冒号。 |

   设备注册成功后，请妥善保管好设备ID和密钥，用于设备接入平台认证。

   **图2** 设备-注册设备成功   
   ![](https://support.huaweicloud.com/usermanual-iothub/figure/zh-cn_image_0000001981487333.png "点击放大")

   ![](https://res-static.hc-cdn.cn/aem/content/dam/cloudbu-site/archive/china/zh-cn/support/resource/framework/v3/images/support-doc-revision-note.svg)说明：

   若密钥丢失，可以按照[设备认证凭证管理](https://support.huaweicloud.com/usermanual-iothub/iot_01_0114.html#ZH-CN_TOPIC_0000001710844018__section95402030162213)中的步骤更新设备密钥，无法找回注册设备时生成的密钥。

   用户可在[设备列表](https://support.huaweicloud.com/usermanual-iothub/iot_01_0065.html)删除不再使用的设备。删除设备不支持撤回，请谨慎操作。
