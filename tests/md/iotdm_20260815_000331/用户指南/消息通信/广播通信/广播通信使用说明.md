#### 操作步骤

1. 设备发起连接鉴权，鉴权参数填写规则参考[MQTT设备连接鉴权](https://support.huaweicloud.com/api-iothub/iot_06_v5_3009.html)。
2. 设备鉴权成功后，发起广播Topic订阅，广播Topic必须为“$oc/broadcast/”前缀，样例如下：

   ```
   $oc/broadcast/test
   ```
3. 应用服务器下发[广播消息](https://support.huaweicloud.com/api-iothub/BroadcastMessage.html)，指定Topic名称和消息内容。

   ```
   POST https://{Endpoint}/v5/iot/{project_id}/broadcast-messages
   Content-Type: application/json
   X-Auth-Token: ********

   {
     "topic_full_name" : "$oc/broadcast/test",
     "message" : "eyJhIjoxfQ=="
   }
   ```

   ![](https://res-static.hc-cdn.cn/aem/content/dam/cloudbu-site/archive/china/zh-cn/support/resource/framework/v3/images/support-doc-revision-note.svg)说明：

   这里Topic必须为“$oc/broadcast/”前缀，消息内容需要使用BASE64编码。
4. 设备接收广播消息，设备接收的广播消息样例如下。

   ```
   Topic: $oc/broadcast/test  
   数据内容：
   {"a":1}
   ```
