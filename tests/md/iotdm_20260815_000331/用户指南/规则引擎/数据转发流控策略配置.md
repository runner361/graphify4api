数据转发流控策略配置
==========

#### 概述

客户可以根据自身的业务场景以及转发目标（如第三方应用服务器等）的性能等情况，在IoT物联网平台上创建不同维度的流控策略，控制IoT物联网平台数据转发到转发目标（如第三方应用服务器等）的流量限制。

#### 流控策略维度

![](https://res-static.hc-cdn.cn/aem/content/dam/cloudbu-site/archive/china/zh-cn/support/resource/framework/v3/images/expand-table.svg)

**表1** 流控策略类型

| 流控策略类型 | 描述 |
| --- | --- |
| 实例级别流控 | 使用此策略类型时，流控的范围为当前实例中所有数据转发的流量，超出流控的数据会被丢弃。 |
| 转发通道流控 | 使用此策略类型时，流控的范围为当前实例中所有转发至指定目标的流量。 |
| 转发规则流控 | 使用此策略类型时，流控的范围为当前实例中所有触发指定转发规则的流量，超出流控的数据会被丢弃。 |
| 转发动作流控 | 使用此策略类型时，流控的范围为当前实例中所有转发至指定动作的流量。 |

#### 使用限制

租户在单个IoT物联网平台实例下最多可以创建4个数据流转流控策略。

#### 操作步骤

1. 访问[设备接入服务](https://www.huaweicloud.com/product/iothub.html)，单击“管理控制台”进入设备接入控制台。选择您的实例，单击实例卡片进入。
2. 单击“规则” ，选择“数据转发” ，选择 “策略配置” ，进入流控策略配置界面。

   **图1** 数据转发-策略配置   
   ![](https://support.huaweicloud.com/usermanual-iothub/figure/zh-cn_image_0000001983504337.png "点击放大")
3. 在弹出的界面中填写相关信息后，单击“确定”即可完成流控策略创建。

   **图2** 数据转发-创建流控策略   
   ![](https://support.huaweicloud.com/usermanual-iothub/figure/zh-cn_image_0000001983627789.png "点击放大")

   ![](https://res-static.hc-cdn.cn/aem/content/dam/cloudbu-site/archive/china/zh-cn/support/resource/framework/v3/images/expand-table.svg)

   **表2** 参数说明

   | 参数名称 | 描述 |
   | --- | --- |
   | 策略名称 | **参数说明：**长度为4-256，只允许中文、字母、数字以及\_?'#().,&%@!-等字符的组合。 |
   | 描述 | **参数说明：**关于该策略的描述，长度为4-256，只允许中文、字母、数字以及\_?'#().,&%@!-等字符的组合。 |
   | 流控大小 | **参数说明：**取值范围为1-1000。 |
   | 流控策略类型 | **参数说明：**包括实例级别流控、转发通道流控、转发规则流控、转发动作流控四种流控策略类型。 |
   | 转发目标 | **参数说明：**当流控策略类型为转发通道流控时生效，对应当前实例支持的转发通道类型。 |
   | 绑定规则 | **参数说明：**当流控策略类型为转发规则流控时生效，对应IoT物联网平台上的数据转发规则。 |
   | 绑定动作 | **参数说明：**当流控策略类型为转发动作流控时生效，对应IoT物联网平台上的数据转发动作。 |
